# Code of conduct

Treat contributors and users with respect. Critique code and ideas with specific evidence. Harassment, threats, discriminatory abuse, unwanted sexual attention, doxxing and disclosure of private information are not acceptable in project spaces.

Maintainers may edit or remove contributions, restrict participation, or close discussions that violate these standards. Decisions should be proportionate to the behavior and protect affected people.

To report misconduct, contact the maintainer privately through a channel they provide. If no private channel is available, request one without identifying the affected person or posting sensitive details. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
